Configure and run

The fetcher automatically uses data/public-source-config.example.json. Copy it to data/public-source-config.json to edit URLs or enable company-specific pages, then run npm run data:fetch -- --symbols BEL POWERGRID SUNPHARMA LT BRITANNIA --timeout 8. The fetcher tries sources in order and writes only observed values.
