# YieldAlpha dashboard code provenance

## What was actually used

The updated workbook was generated by importing the existing
`india_stock_methodology_weekly_dashboard.xlsx` workbook with `artifact_tool`,
adding/updating sheets and ranges, and exporting a new XLSX file.

The exact workbook-update script is included as:

- `yieldalpha_dashboard_update_exact.py`

## How the data was fetched for the research

There was **no standalone requests/API-key script** used for the original research
dataset.

The values were gathered interactively during the ChatGPT research session through
web retrieval/search and cross-checking from sources including:

- NSE / Nifty Indices
- BSE references
- company investor-relations pages
- Moneycontrol
- Economic Times Markets
- Upstox
- Dhan
- ICICI Direct
- EquityPandit
- StockPriceArchive
- Goodreturns
- Investing.com India
- Reuters
- IPO Central

No API key was used for that research workflow.

The resulting values/source URLs were then stored in the CSV/workbook and later
carried into the updated dashboard.

## Fresh-data reference implementation

`yieldalpha_fresh_data_fetch_scaffold.py` is **new reference code** showing how the
production application should fetch/normalize data through provider adapters.

It was **not** used to generate the earlier research results and should not be
described as such.

Before using any provider in a distributed/commercial PWA, verify its automated
access, licensing and redistribution terms.
